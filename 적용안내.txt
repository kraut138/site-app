"2. 동.호수 생성" 탭 추가 업데이트

수정 내용
- index.html (저장소 맨 위/첫 화면 파일) 상단 네비게이션에 "2. 동.호수 생성" 탭을 새로 추가했습니다.
  위치: 기존 "1. 공종별 QR 생성소" 와 "3. 각 호실 정보 & 평면도" 탭 사이.
- 새 탭에는 동 / 호수 / 타입을 각각 직접 입력할 수 있는 입력창 3개와 "동·호수 등록" 버튼을 만들었습니다.
  (입력창 디자인은 기존 "3. 각 호실 정보 & 평면도" 탭의 선택창 스타일을 그대로 참고했습니다.)
- 등록한 내용은 오른쪽에 카드 목록으로 표시되고, 각 항목의 휴지통 아이콘으로 삭제할 수 있습니다.
- 등록된 목록은 브라우저의 localStorage에 저장되어 새로고침해도 유지됩니다.
  (주의: 서버/DB에 저장되는 것이 아니라 "그 브라우저"에만 저장되므로, 다른 PC·다른 브라우저·시크릿창에서는 보이지 않습니다.)

기존 저장소에 적용하는 방법 (GitHub Desktop)
1. 이 ZIP 압축을 풉니다.
2. 기존 GitHub 저장소 폴더의 맨 위(루트)에 있는 index.html 파일을 이 수정본의 index.html로 덮어씁니다.
   - 주의: app/index.html(실제 React 앱 진입 파일)이 아니라, 저장소 최상단에 있는 index.html입니다.
3. GitHub Desktop을 열어 변경 내용(index.html)을 확인합니다.
4. 커밋 메시지를 입력(예: "2.동호수 생성 탭 추가")하고 main 브랜치에 Commit → Push 합니다.
5. GitHub 저장소의 Actions 탭에서 "Deploy to GitHub Pages" 작업의 build/deploy가 성공하는지 확인합니다.
6. 배포 완료 후 사이트 첫 화면에서 Ctrl+Shift+R(강력 새로고침)로 새로고침한 뒤 "2. 동.호수 생성" 탭을 확인합니다.

참고 / 제한 사항
- 이번 수정은 저장소 맨 위(첫 화면) index.html에만 적용됩니다. app/ 폴더 안의 실제 React 앱(src/*.jsx, Firebase 연동 부분)에는 영향이 없습니다.
- 새로 만든 "2. 동.호수 생성" 탭은 "등록·목록 보기" 전용 화면입니다. 지금 단계에서는 "1. 공종별 QR 생성소"와 "3. 각 호실 정보 & 평면도" 탭의 동/호수 선택 목록과 자동으로 연동(동기화)되지는 않습니다.
  해당 두 탭의 선택 목록까지 이 등록 내용을 따라가도록 연동하려면 추가 작업이 필요하니 말씀해주시면 이어서 진행하겠습니다.

검증 범위
- HTML 태그 구조(여는/닫는 태그 짝)와 JavaScript 문법 오류 여부를 점검했습니다.
- 실제 브라우저 클릭 동작 테스트나 GitHub Pages 배포 테스트는 이 작업 환경에서 수행하지 못했습니다.

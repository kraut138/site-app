"공사현황 대시보드"에 건물 골구도 뷰어 넣기 업데이트

수정 내용
- "공사현황 대시보드" 탭(맨 첫 화면)에서 기존에 "실시간 현장 음성 보고 피드 (Live Feed)" 카드가 있던
  자리(화면 좌측, 2칸 폭)에 "4. 건물 골구도 뷰어" 탭의 내용과 기능을 그대로 넣었습니다.
  - 동별 골구도(호실 칸을 눌러 공정 상태를 확인), 음성 보고로 자동 반영된 완료 표시, '다시 계산' 기능 등
    4번 탭에 있던 기능이 대시보드에서도 동일하게 동작합니다.
  - 우측에 있던 "공종별 검측 승인 현황" 카드는 그 자리에 그대로 유지했습니다.
- "실시간 현장 음성 보고 피드 (Live Feed)" 카드는 그 아래, 화면 전체 폭을 쓰는 새 줄로 옮겼습니다.
  내용과 동작(실시간 갱신, 연결 끊기면 '다시 연결' 버튼 등)은 이전과 완전히 동일합니다.

참고 사항 (꼭 확인해 주세요)
- 이번 변경에서는 기존 "4. 건물 골구도 뷰어" 탭 자체는 지우지 않고 그대로 남겨두었습니다.
  요청하신 내용이 "대시보드 안에 넣어달라"였고 "4번 탭을 없애달라"는 말씀은 없었기 때문입니다.
  → 즉 지금은 같은 골구도 화면을 대시보드와 4번 탭, 두 곳에서 볼 수 있는 상태입니다.
  → 만약 4번 탭을 없애고 뒤 탭들의 번호를 하나씩 당기기(5→4, 6→5...)를 원하시면 말씀해 주세요. 바로 추가로 반영해 드리겠습니다.

수정된 파일 (2개, 기존 저장소의 같은 경로에 그대로 덮어쓰면 됩니다)
- src/App.jsx                      (대시보드 탭에 골구도용 데이터 전달)
- src/platform/PortalDashboard.jsx  (대시보드 레이아웃 변경 - 골구도 뷰어 추가, Live Feed 위치 이동)

기존 저장소에 적용하는 방법 (GitHub Desktop)
1. 이 ZIP의 압축을 풉니다. 압축을 풀면 "src" 폴더가 나옵니다.
2. 기존 GitHub 저장소 폴더(사이트 코드가 있는 폴더)를 엽니다.
3. 이 ZIP 안의 src/App.jsx 를 기존 저장소의 src/App.jsx 위에 덮어씁니다.
4. 이 ZIP 안의 src/platform/PortalDashboard.jsx 를 기존 저장소의 src/platform/PortalDashboard.jsx 위에 덮어씁니다.
   - 다른 파일은 이 ZIP에 없으니 그대로 두면 됩니다. 지우지 마세요.
5. GitHub Desktop을 열어 "Changes" 탭에서 2개 파일이 바뀐 것을 확인합니다.
6. 커밋 메시지를 입력합니다. 예: "대시보드에 건물 골구도 뷰어 추가, Live Feed는 아래로 이동"
7. main 브랜치에 Commit → Push 합니다.
8. GitHub 저장소 페이지의 Actions 탭에서 "Deploy to GitHub Pages" 작업이 성공(초록색 체크)하는지 확인합니다.
9. 배포가 끝나면 사이트를 Ctrl+Shift+R(강력 새로고침)로 새로고침한 뒤, "공사현황 대시보드" 탭에서
   좌측에 건물 골구도 뷰어가, 그 아래에 실시간 음성 보고 피드가 보이는지 확인합니다.

검증 범위
- 수정된 2개 파일을 포함한 전체 앱 코드를 실제 번들러(esbuild)로 빌드해서 문법 오류나 깨진 import가 없는 것을
  확인했습니다(866KB 정상 빌드 완료).
- 다만 이 작업 환경에는 Firebase 연결이나 실제 브라우저 화면이 없어서, 실제 배포 후 화면이 의도한 대로
  보이는지는 GitHub Actions 배포 후 사이트에서 직접 확인해 주셔야 합니다.
